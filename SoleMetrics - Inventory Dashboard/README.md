# SoleMetrics

React Native shoe analytics dashboard using TypeScript and react-native-gifted-charts.

## Run

1. Install dependencies:
   npm install

2. Start Expo:
   npx expo start

3. Open with Expo Go or an Android/iOS simulator.

## Structure

- `app/index.tsx` — dashboard screen
- `components/` — reusable chart/stat components
- `data/mockShoes.ts` — test dataset
- `types/Shoe.ts` — TypeScript data model

The mock data is intentionally structured for sales, inventory, category, brand, gender, color, rating, and size visualizations.
