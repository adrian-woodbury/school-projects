# School Projects — East Carolina University (B.S. Computer Science)

Selected coursework from my Computer Science degree.

## SoleMetrics - Inventory Dashboard

React Native/Expo dashboard for shoe inventory analytics. Features interactive charts, category breakdowns, and responsive stat cards.

- **Stack**: React Native, Expo, TypeScript
- **Features**: Sales overview, category/brand charts, product modals, time-range filtering

## Information Retrieval

- **Lucene/** — Search application built on Apache Lucene, indexing and querying the Cranfield collection.
- **Project2/** — Larger IR project: a custom inverted index and retrieval over the Cranfield corpus, with a written report (`ReadMe.pdf`).
- **IR-LucenePractice/** — Early Lucene warm-up exercise.

> The Cranfield test dataset (~1,400 documents) is excluded from version control; the retrieval code and reports are what's here.

## Computer Graphics

- **3D Graphics Labs/** — Raytracer in Python: sphere/plane intersection, Phong shading, shadows. Lab images and scene configuration files included.
- **Final Project - Solar System/** — An interactive WebGL solar system: eight planets and the sun rendered as 3D spheres with GLSL shaders, real-time orbits, and mouse-controlled camera. Includes the project report.

## Stack

Java · Apache Lucene · Python · WebGL / GLSL · JavaScript · React Native · TypeScript
